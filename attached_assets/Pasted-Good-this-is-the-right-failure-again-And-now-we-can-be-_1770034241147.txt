### What’s actually happening on this screen

On this portal page, **the visible text is not part of a normal `div` text node**.

The tile is rendered as:

* an **anchor or clickable container**
* with **nested elements and icons**
* and the text is often injected or wrapped in spans that `hasText` does not reliably match in headless mode

That’s why **both** of these fail:

* `text=Sign in with Access People Planner Account`
* `div:has-text("Access People Planner")`

Visually correct, DOM-wise unreliable.

This is very common with Access UIs.

---

## The reliable mental model for this screen

Business logic:

* There are **exactly three tiles**
* The **first tile** is always “Access People Planner Account”
* You never want the other two

So the automation should **not search by text at all**.
It should select by **structure and position**, like a human would.

This is both safer and more stable long-term.

---

## The selector that actually works here

### Use role-based + position selection

Playwright can target clickable elements by role.

On this page, each tile is a **link**.

### ✅ Correct approach

```ts
const tiles = page.getByRole('link');
await tiles.first().waitFor({ state: 'visible', timeout: 30000 });
await tiles.first().click();
```

This clicks:

* the first clickable tile
* regardless of text
* regardless of DOM nesting

This matches exactly what you do manually.

---

## If you want to be slightly more defensive

You can also assert there are 3 tiles:

```ts
const tiles = page.getByRole('link');
await expect(tiles).toHaveCount(3);
await tiles.first().click();
```

That way if Access ever changes the layout, you’ll know immediately.

---

## Why `getByRole` is the right tool here

* It uses **accessibility tree**, not raw DOM
* Works even when text is split across spans
* Much more reliable in headless Chromium
* Designed for exactly this kind of UI

This is one of those cases where role-based selectors beat CSS/text selectors.
