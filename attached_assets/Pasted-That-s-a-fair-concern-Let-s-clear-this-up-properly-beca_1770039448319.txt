## Why the login page was blank before

The blank page did **not** happen because of your selectors.

It happened because **all of these were true at the same time**:

1. You were running on **Linux / Replit**
2. You were using **headless browsers**
3. People Planner was enforcing **IE-only / legacy checks**
4. The browser failed those checks
5. Result: page loads, but **nothing is rendered**

That’s why screenshots were empty.

---

## Why Edge + IE-mode is different (and when it works)

Edge IE-mode **only works correctly when**:

* ✅ Running on **Windows**
* ✅ Using **real Edge**
* ✅ **NOT headless**
* ✅ IE-mode enabled **in Edge settings**
* ✅ Using a **persistent browser profile**

If *any one* of those is missing, you can still get a blank page.

---

## The two mistakes that usually cause a blank page even on Windows

### ❌ Mistake 1: Running headless

IE-mode **does not render in headless mode**.

If you do this, you’ll get a blank page again:

```ts
headless: true ❌
```

You must use:

```ts
headless: false ✅
```

---

### ❌ Mistake 2: Not using a persistent Edge profile

IE-mode settings are stored **per Edge profile**.

If Playwright launches Edge with a temporary profile, IE-mode rules are ignored.

That results in:

* login page loads
* IE warning logic triggers
* page stays blank

---

## The correct, working Edge + IE-mode setup (this matters)

### 1. Configure IE-mode in Edge (once, manually)

You already know this part, but it must be done **before automation**:

* `edge://settings/defaultBrowser`
* Allow IE-mode
* Add:

  ```
  https://www.peopleplanner.biz
  ```
* Restart Edge
* Confirm manually that People Planner opens in IE-mode (IE icon in address bar)

---

### 2. Launch Edge with a persistent profile (critical)

This is the part most people miss.

```ts
import { chromium } from 'playwright';

const context = await chromium.launchPersistentContext(
  'C:/pp-edge-profile', // any real folder
  {
    channel: 'msedge',
    headless: false,
    viewport: null
  }
);

const page = await context.newPage();
```

Why this works:

* Edge uses the **same profile** every time
* IE-mode rules are applied
* Cookies, compatibility settings, and rendering all work
* No blank page

---

### 3. Navigate normally

```ts
await page.goto(
  'https://www.peopleplanner.biz/Security/login.aspx',
  { waitUntil: 'domcontentloaded' }
);
```

At this point:

* The page should **visibly render**
* Client ID input should be visible
* No “IE only” warning
* No blank screen

If it’s blank **here**, IE-mode is not active.

---

## How to confirm IE-mode is actually on (important check)

When the browser opens:

* Look at the address bar
* You should see the **IE icon**
* Edge menu will say “Internet Explorer mode”

If you don’t see that:

* Automation will fail
* Blank pages will happen
* Login will be blocked
