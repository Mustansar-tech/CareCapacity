## The selector that actually works here

Use **label-based or nearby-text selection**.

### Recommended approach

```ts
const userCodeInput = page.locator('text=User code')
  .locator('xpath=following::input[1]');

await userCodeInput.waitFor({ state: 'visible', timeout: 30000 });
await userCodeInput.fill(USERNAME);
```

Then for password:

```ts
const passwordInput = page.locator('text=Password')
  .locator('xpath=following::input[1]');

await passwordInput.fill(PASSWORD);
```

This matches **exactly** what a human sees and does.

No guessing. No `.first()`.
