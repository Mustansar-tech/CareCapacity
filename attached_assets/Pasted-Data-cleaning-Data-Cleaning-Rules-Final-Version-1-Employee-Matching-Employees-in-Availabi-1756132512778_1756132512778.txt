📘 Data Cleaning Rules (Final Version)
1. Employee Matching
•	Employees in Availability Export were matched to Care Pro Guaranteed Hours using a name normalisation process:
o	Removed titles (Mr, Miss, Mrs, Dr, etc.).
o	Removed (NL), (GH) and commas.
o	Lowercased and re-sorted tokens for consistency.
________________________________________
2. Contracted Daily Hours
•	Formula:
Contracted Daily Hours = Contracted Weekly Hours ÷ Days Available
•	Days Available = number of unique dates an employee appears in the Availability file (regardless of status).
________________________________________
3. Daily Grouping (Option 2 – Enhanced)
For each Employee × Date:
•	If one status only → keep it as is.
•	If multiple non-overlapping statuses → keep separate rows, concatenate time windows, and keep hours as given.
•	If statuses conflict → apply priority rule:
Maternity > Sick > Holiday > Compassionate Leave > Other Unavailable > Pre-Agreed Appointment > Available
________________________________________
4. Capacity Adjustments
•	If an employee has Available + Leave on the same date:
o	Available Hours = Contracted Daily Hours – total leave hours (capped at 0).
o	Leave rows are retained for transparency.
•	Leave hours are capped at Contracted Daily Hours (so never more than daily contract).
•	Net Capacity is added:
o	Available rows → adjusted Available Hours.
o	Leave rows → always 0.
________________________________________
5. Output Columns
The final cleaned dataset contains:
•	Employee Name
•	Contracted Weekly Hours
•	Contracted Daily Hours
•	Date
•	Status (Available, Holiday, Sick, etc.)
•	Time Windows (merged, e.g. "08:00–12:00; 14:00–18:00")
•	Hours (per status, after adjustments)
•	Net Capacity (true usable hours for scheduling that day)
________________________________________
✨ With these rules, the dataset is:
•	Transparent (all statuses visible).
•	Accurate (no inflation beyond contracts).
•	Dashboard-ready (Net Capacity for KPI tracking).
•	Scheduler-friendly (clear daily statuses + time windows).
