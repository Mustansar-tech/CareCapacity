## What the error actually means

> `page.fill: Timeout 30000ms exceeded`
> waiting for `input[name="ClientID"], input#ClientID`

This means **the Client ID field never appeared in the main DOM** within 30 seconds.

On People Planner, this happens for one of these reasons (very common):

1. The Client ID input is inside an **iframe**
2. The page loads slowly and you’re trying to fill too early
3. The site redirects before rendering the input
4. Headless mode loads a slightly different structure

From your screenshots and URL, **#1 is the real reason**.

---

## Important People Planner detail (key insight)

The Client ID login page is **iframe-based**.

Visually it looks like a normal page, but the actual input lives inside an embedded frame. Playwright will NOT see it with `page.fill()`.

That’s why your selector never resolves.

---

## The correct way to handle this (this will fix it)

You must:

1. Wait for the iframe
2. Target the iframe
3. Fill the Client ID inside the iframe

## Step-by-step fix (TypeScript / Playwright)

### ❌ What you have now (why it fails)

```ts
await page.goto(LOGIN_URL);
await page.fill('input[name="ClientID"]', clientId);
```

This will **never** work reliably.

---

### ✅ Correct implementation

#### 1) Go to login page and wait properly

```ts
await page.goto(LOGIN_URL, { waitUntil: 'domcontentloaded' });
```

Do **not** use `networkidle` here. People Planner keeps background requests open.

---

#### 2) Wait for the iframe

Most People Planner pages use **one main iframe**. Safest approach:

```ts
const frame = await page.frameLocator('iframe').first();
```

If you want to be stricter:

```ts
const frame = page.frameLocator('iframe[src*="login"]');
```

---

#### 3) Wait for the Client ID field inside the iframe

```ts
await frame.locator('input[name="ClientID"], input#ClientID')
  .waitFor({ timeout: 30000 });
```

---

#### 4) Fill and submit

```ts
await frame.fill('input[name="ClientID"], input#ClientID', clientId);
await frame.click('button:has-text("Login")');
```

---

## Defensive version (recommended)

People Planner is flaky. This version handles slow loads:

```ts
await page.goto(LOGIN_URL, { waitUntil: 'domcontentloaded' });

const frame = page.frameLocator('iframe').first();

await frame.locator('input[name="ClientID"], input#ClientID')
  .waitFor({ state: 'visible', timeout: 30000 });

await frame.fill('input[name="ClientID"], input#ClientID', clientId);
await frame.click('button:has-text("Login")');
```
