You’ve got two separate things causing this:

1. **You hide the 4-input uploader whenever `latestData` exists**
   Your top “Upload Files” card (the one that **does** include CG Data) is wrapped in:

   ```jsx
   {!processedData && !latestData && ( ... )}
   ```

   Because `react-query` quickly returns `latestData`, that card never renders. So you never see the 4 inputs there.

2. **The Overview tab uploader still has only 3 inputs**
   Inside `content-overview` you render Availability, Guaranteed, and Demand — but **no CG Data** input. (Your Process button in Overview also requires `files.cgData`, so it stays disabled there.)

Also: you pasted the entire component **twice** in the same file (two `export default function Dashboard()` blocks). That will either fail to compile or the second one will “win,” and it still has the same 3-input Overview issue.

  ```
* {!processedData && !latestData && (

- {!processedData && (
  \<Card ...> ... </Card>
  )}

  ```
  ```

* **Add CG Data to the Overview tab uploader** (and make it a 4-column grid):

  ```
* <div className="grid grid-cols-1 md:grid-cols-3 gap-6 mb-6">

- <div className="grid grid-cols-1 md:grid-cols-4 gap-6 mb-6">
  ```
